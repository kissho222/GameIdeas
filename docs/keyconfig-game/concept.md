# キーコンフィグのないゲーム

## ステータス
短編ゲーム案

## 一言で
チュートリアル中のプレイヤー操作を、その場で押したキーへ永久に割り当てていくゲーム。  
一度使ったキーは再利用できず、最後にはキーボードのほぼ全部に何かが割り当てられる。

## 体験の中心
- 「前に歩いてみよう」で押したキーが、そのまま前進キーになる
- 間違えてもやり直せない
- 既に使ったキーへ別操作は割り当てられない
- 不要そうな動作にも容赦なくキー設定を要求する
- 最終的に、自分で作った異常な操作体系で簡単なアクションや謎解きを突破する

## 現在決まっていること
- 基本移動だけで終わらない
- 「拾う」「置く」「投げる」「話しかける」「踊る」等にもキーを要求
- 使用済みキーは再割り当て不可
- 誤入力もゲーム体験として保存
- 短編向け

## 未決定
- 必須アクション数
- マウスボタンや修飾キーを対象にするか
- クリア不能状態をどこまで許容するか
- アクセシビリティ上の救済

## 設計意図
キーコンフィグを快適にするゲームではなく、「自分で自分の操作体系を壊していく」過程そのものをパズルにする。

## 次に壁打ちしたいこと

- クリアまでのステージ構成
- 詰み防止の最低限ルール
