# ゆっくりにはなりたくない！

## ステータス
アイデア段階

## 一言で
「うすのろ」系のカードゲームを元に、役を揃えたプレイヤーが好きなタイミングで中央の運搬物へ手を伸ばし、それを合図に全員で争奪・運搬・妨害する対戦パーティーゲーム。
4回負けると敗北。負けるほど「ゆ・っ・く・り」が集まり、完全に「ゆっくり」へ近づいていく。

## モチーフ / 方向性
- 東方Project二次創作として作る案が有力
- キャラクターごとの性能差は設けない
- 東方要素は主に敗北演出、スペル名・効果、演出上のネタに使う
- 「ゆっくり」の文字を敗北進行として使う
  - 1敗ごとに「ゆ → ゆっ → ゆっく → ゆっくり」と進行
  - 4敗で最終敗北
- 完全な四肢欠損表現ではなく、段階的にゆっくり化・デフォルメ化する案

## ラウンド基本ルール
- プレイヤーは数字カードを交換し、規定枚数を揃えることを狙う
- 役が揃っても、その瞬間に争奪開始にはならない
- 揃えたプレイヤーは、次のカード交換まで好きなタイミングで中央の運搬物へ触れられる
- 最初に役を揃えたプレイヤーが運搬物へ触れた瞬間、他プレイヤーも触れてよい
- 参加人数より運搬物を1つ少なくする
  - 例：4人なら3個
- 取れなかった1人は運搬役になれず、妨害側へ回る
- 運搬物をゴールまで持っていけた順に結果が決まる

## 運搬操作
- 現在は「コイン」を仮称としている
- コインにこだわる必要はなく、速く動かしすぎると落とす理由が直感的に伝わる「スプーン＋卵」案あり
- マウス操作 / スワイプで運搬
- 速く動かしすぎると運搬物を落とす
- 単純な反射速度だけでなく、「急ぎたいが急ぎすぎると失敗する」操作を中心にする

## フェイントとお手付き
### お手付き条件
以下はお手付き。
- 誰も役を揃えていないのに運搬物へ触る
- 誰かが役を揃えていても、その本人より先に触る

### 読み合い
- コインへカーソルを近づける、触る直前まで動かすなどの「触るフリ」は合法
- 役を揃えた本人は、他人のお手付きを誘うためにフェイントできる
- お手付きを重罰にはしない
- 故意のお手付きで敗北スペルを稼ぐ戦略も完全には禁止しない
- 通常敗北時はスペル候補3枚、お手付き敗北時は候補2枚程度に減らす案
  - 故意利用は可能だが、通常敗北より成長効率が悪い形にする

### お手付き関連スペル案
- 1回だけお手付きを免除
  - 誰も揃っていなくても運搬物へ触れられる
  - 触れた運搬物は元の位置へ戻る
  - 他プレイヤーを釣るための合法フェイントとして使える
  - 実際にゴールまで運んだ場合はお手付き扱い、などの調整案あり

## 妨害 / 復活
- 運搬物を取れなかったプレイヤーは暇にならず、妨害役として参加継続
- 妨害は『みそボン』のように復活を狙うための行動
- 他人が持っている運搬物を正確にクリックできれば落とせる
- 妨害そのものに大きなリスクは不要
- 妨害成功後、落ちた運搬物の再争奪や復活へつながる仕組みを想定
- 「一度取れなかったらビリ確定」ではなく、最後まで復帰可能にする
- 最後の1対1が延々と足の引っ張り合いにならない収束ルールは要調整

## 同時取得
- 複数人がほぼ同時に同じ運搬物へ触れた場合、単純に先着判定にしない
- 一定の同着判定窓内なら、その運搬物が弾けて再抽選 / 再配置される
- オンライン時のラグ差・ホスト有利をゲーム内処理へ吸収する狙いもある

## 敗北とスペル
### 用語
- 交換している通常の数字カードは「カード」
- 敗北時に獲得する特殊能力は「スペル」
- 「カード」という語の二重使用を避ける

### 敗北
- 4回負けると最終敗北
- 負けるたびに「ゆっくり」化が1段階進む
- 同時にスペルを獲得し、負けている側ほど逆転手段が増える

## スペルTier
東方らしさを優先し、現時点では以下のTier名を想定。
- Easy
- Normal
- Hard
- Lunatic

基本的には敗北が進むにつれて Easy → Normal → Hard の順に出やすくなる。
低確率で本来より上のTierが抽選されることもある。

Normal / Hard帯には「ランダムにスペルを2枚獲得」のようなギャンブル系スペルを入れる案あり。

## スペル候補

### 運搬 / 安定
- 早く動いても運搬物を落としにくくなる
- 妨害で運搬物を落とされても、すぐに拾えるようになる

### 妨害
- 妨害で運搬物を奪いやすくなる
- 複数人相手に妨害できるようになる

### フェイント / 混乱
- お手付き1回免除
- 偽物の運搬物を混ぜる。取得者だけ本物を見分けられる
- 偽物の運搬物を5個追加する。誰も見分けられない
- 全員、誰がどのカーソルか分からなくなる

### 情報
- 自分以外で2枚揃ったプレイヤーが分かる
- 自分以外で3枚揃ったプレイヤーが分かる
- 3回だけ、誰かが4枚揃えたことが分かる
  - 取得者だけ通知される
  - 3試合だけ、取り合いが始まるターンを把握できる
  - Hard想定
- 開始時に指定した数字カード1枚の場所が常に分かる
  - 交換されて移動しても追跡できる
  - Normal想定

### カード干渉
- 自分以外全員のスペルから、毎回ランダムで1枚無効化する
  - 「数字カード」ではなく「スペル」を対象とする
  - Hard以上を想定
- 手札にジョーカーを1枚手に入れる

### 時間 / 操作干渉
- 次の1ターン、自分以外のカーソルの動きが遅くなる

### 保険
- 敗北を一度だけ帳消しにして、その試合を仕切り直す
  - その場合スペルは手に入らない

### ギャンブル
- NormalまたはHard帯からランダムでスペルを2枚獲得する

## Tier設計の方向性
- Easy：自分を安定させる、分かりやすい補助
- Normal：情報・フェイント・軽い妨害
- Hard：他人の行動やスペルへ直接干渉する
- Lunatic：ルールや情報そのものを大きく混乱させる

数値強化だけを並べず、
- 偽物
- お手付き免除
- 情報取得
- カーソル識別不能
- スペル無効化

のように、ルールや読み合いを変える能力を主役にする。

## オンライン実装上の課題
- ラグ差
- ホスト有利
- 同時取得判定
- カーソル位置と妨害判定の同期
- 「触った順」を厳密な通信到着順にすると不公平になる

同時取得時に弾けて再抽選する処理など、通信上の曖昧さをゲームルールへ吸収する方向で検討。

## 設計意図
このゲームの中心は、数字カードを揃えること自体ではなく、

1. 誰かが揃ったか読む
2. 揃えた本人がいつ手を伸ばすか読む
3. フェイントでお手付きを誘う
4. 一斉に運搬物を取り合う
5. 急ぎすぎないよう運ぶ
6. 取れなかった側が妨害して復活を狙う
7. 負けるほどスペルが増え、盤面が壊れていく

という流れ。

脱落者を観客にせず、4敗する最後まで全員が場へ関与できるパーティーゲームにする。
