# アドセンスウォーズ

## ステータス
アイデア段階

## 一言で
ゲーム内広告そのものを武器・罠・地形として戦う対戦ゲーム。  
実在広告は後から枠を販売できるが、ゲームとしては偽広告だけでも成立させる。

## 体験の中心
- 広告がUIの外側ではなくゲーム世界の攻撃手段になる
- 広告表示による視界妨害と、ゲーム内の物理的効果を組み合わせる
- 「広告枠を買うとゲーム世界に広告が出る」という設定をそのまま商品化可能にする

## 現在決まっていること
- 踏むと広告が画面に出て小ダメージ＋視界妨害する地雷
- 被弾すると一定時間広告が出るフラッシュ系
- 床広告を使ったダメージ床／スロー床
- 野球場の看板のような競争要素のないフィールド広告
- 開始時点では多数の架空広告を用意し、広告がなくてもゲームとして完成させる
- 後から企業・個人が同じ枠を購入可能
- 連絡があれば専用外観や専用エフェクトなど特別対応も検討

## 未決定
- 対戦形式
- 広告購入の価格・審査・規約
- Steam等プラットフォーム規約との整合
- 広告が強さに影響しすぎない設計

## 設計意図
「広告を入れて収益化したゲーム」ではなく、「広告という概念自体をゲームメカニクスにした作品」にする。  
広告主が一件も来なくても成立することを前提とする。
