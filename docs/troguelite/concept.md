# トローグライト

## ステータス
アイデア段階

## 一言で
困った仲間と変な仲間ばかりを編成し、仲間割れや味方巻き込みを利用して敵を倒すデッキ構築ローグライト。

## 体験の中心
- 味方への攻撃、反撃、自傷、支援反応などを連鎖させる
- 「味方同士が噛み合わない」こと自体を攻略リソースにする
- 普通に敵だけを殴れる安全なキャラは主人公くらい
- トロール行為を排除するのではなく、ビルドの一部として利用する

## 現在決まっていること
- 味方ごと攻撃するキャラや反撃持ちを組み合わせる
- 回復、毒なども広く「支援／状態変化」としてトリガーにできる
- 特定ステータス低下を条件に別ステータスが上がる等の変則ギミック
- わざと負けようとするトロール的なキャラもギミック化したい
- 世界観上も「まともなやつがほとんどいない」方向

## 未決定
- 戦闘UIとカード／スキルの基本単位
- パーティ人数
- 敵側にも同様の仲間割れを持たせるか
- 敗北を狙うキャラをどう攻略上成立させるか

## 設計意図
協力的なパーティを最適化するゲームではなく、問題児同士を衝突させ、その副作用をプレイヤーが利益へ変えるゲームにする。

- 戦闘1ターンの具体例
