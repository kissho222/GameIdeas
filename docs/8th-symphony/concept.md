# 8番楽章

## ステータス
アイデア段階

## 一言で
吹奏楽部の指揮者になり、演奏中にミスしている奏者を音で見つけて指導するゲーム。  
「8番出口」型の異変探しを、視覚ではなく演奏の違和感に置き換える。

## 体験の中心
- 演奏を聴き分けること自体をゲームにする
- 演奏中に歩き回り、立体音響で怪しいパートへ近づく
- 間違っていないと思えばそのまま進む
- ミス奏者を見逃すと最終的なコンクール結果に影響する

## 現在決まっていること
- 最初は小編成・アンサンブルから始め、徐々に大編成へ増やす
- 立体音響が重要
- カジュアルモードと本格モードを分けたい
- リズムのズレ、音程、入りのタイミングなど複数種類のミス候補がある
- 映画『セッション』的な、厳しい指導演出をモチーフにした特殊モード案がある

## 未決定
- 本格モードで要求する音楽知識の深さ
- 演奏素材をどう用意するか
- 生演奏収録、MIDI、音源ライブラリのどれを軸にするか
- 同じ曲を何度も遊べる仕組み

## 設計意図
音ゲーではなく「聴診するゲーム」にしたい。  
正確にボタンを叩くのではなく、音場の中を動き、違和感の発生源を特定することが主役。

## 次に壁打ちしたいこと
- 1ステージ分の具体的な進行
- カジュアル／本格の差
- 必要な音源制作コスト
