# GameIdeas

ゲームアイデアと設計メモの保管庫。

このリポジトリは、実装タスクを管理する場所ではなく、ChatGPT等との壁打ちである程度着地した**仕様・設計意図・将来構想**を残すための場所です。

## 運用方針

1. アイデア出しの最中はチャットで自由に考える
2. 方向性や仕様がある程度固まったら `docs/<game>/concept.md` に記録する
3. 実装直前になったら必要に応じて設計を分割する
4. Unityプロジェクトを作って本格開発を始める段階で専用リポジトリへ昇格する
5. 実装タスク・Issueと、永続的な設計docsは分ける

## Docsの役割

- **concept / design**: 現在の仕様、設計意図、将来構想
- **roadmap**: 実装開始後の大まかな実装順
- **Issue / task**: 具体的な作業指示

「なぜこうしたか」をTaskの山から発掘しなくて済む状態を目標にする。
